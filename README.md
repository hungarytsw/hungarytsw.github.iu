# Tíz Szó — 하루 열 단어, 헝가리어 🇭🇺

개인용 헝가리어 단어 학습 웹앱. 별도 서버·설치 없이 브라우저만으로 동작하며, 진도는 브라우저(localStorage)에 저장됩니다.

## 학습 방식

- **하루 10단어** × 20일 = 기본 200단어 (주제별 구성: 인사, 숫자, 음식, 동사, 형용사 …)
- **추가 단어 팩** — 홈에서 버튼 한 번으로 심화 100단어(Day 21–30: 직업, 쇼핑, 헝가리 음식, 방향, 취미, 건강 등)를 더 받을 수 있음
- 각 단어는 **헝가리어 + 이모지 그림 단서 + 한국어 뜻**으로 제시
- **아는 단어 / 모르는 단어 체크** — 플래시카드 뒷면의 ✓/✗ 버튼, 단어장에서도 토글 가능
  - ✗ 몰라요 단어는 매일 복습 목록과 다음 테스트에 자동 포함, 테스트에서 맞히면 자동 해제
- 암기 효율을 위한 장치:
  - **능동 회상** — 카드 앞면(헝가리어)을 보고 뜻을 먼저 떠올린 뒤 뒤집어 확인
  - **매일 확인 퀴즈** — 그날 10단어를 4지선다로, 틀리면 맞힐 때까지 재출제
  - **전날 복습** — 매일 학습 시작 전에 어제 단어 + 몰라요 표시 단어 훑기
- **5일마다 테스트** — 최근 50단어 + 이전 오답 + 몰라요 표시 단어 (헝가리어→뜻, 뜻→헝가리어 혼합)
- **오답 이월** — 테스트에서 틀린 단어는 오답 노트에 담겨 다음 테스트에 다시 출제, 맞히면 제거
- 테스트를 통과해야 다음 날 학습이 열립니다

## 사용법

`index.html`을 브라우저에서 열면 끝. GitHub Pages로 배포하려면:

1. 저장소 **Settings → Pages** 에서 Source를 배포할 브랜치로 설정
2. 잠시 후 발급되는 주소로 접속 (모바일에서도 잘 동작합니다)
